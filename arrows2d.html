深圳市星伦智游网络科技有限公司（以下简称“我们”）是《箭头了箭》（以下简称“本游戏”）的运营者。我们重视您的个人信息和隐私安全，并依照适用的法律法规处理和保护您的个人信息。

请您在使用本游戏前完整阅读并理解本隐私政策，尤其是以加粗方式提示的内容。您可以自主选择是否同意本隐私政策；未经您同意，我们不会预初始化或正式初始化会处理个人信息的第三方业务 SDK，包括不会调用友盟 U-APP 移动统计 SDK 的 UMConfigure.preInit 或 UMConfigure.init，也不会初始化 Dirichlet 聚合广告 SDK（TapADN SDK）或 TapSDK，不会发起广告、统计或账号服务请求。只有您主动点击“同意”后，我们才会按照下文说明初始化并开始相应处理。若您不同意本隐私政策，我们将无法向您提供需要处理个人信息的游戏及联网服务。

重点说明：
  • 我们不会因为您同意本隐私政策而一次性收集全部信息，仅在您使用具体功能时，按照最小必要原则处理相应信息。
  • 电话状态、位置、存储、通知等敏感权限不会由我们默认开启；需要时会通过系统授权弹窗单独征求您的同意，您可以拒绝或撤回。
  • 在您同意后，Unity3D 框架会通过 SDK 自动采集方式读取 AndroidID，并查询设备支持的特定类型传感器列表（例如加速度计、陀螺仪、重力、线性加速度、旋转矢量、磁场等），用于游戏引擎运行、输入适配、设备兼容、故障排查和安全保障；查询传感器列表不代表持续读取传感器测量数值。本游戏及相关 SDK 还可能读取设备 MAC 地址，用于网络连接、设备识别、服务稳定、广告监测归因和反作弊。具体处理方、目的和范围见本政策第一、第四部分。
  • 本游戏使用 Dirichlet 聚合广告 SDK（TapADN SDK）进行广告聚合，当前接入穿山甲广告 SDK、腾讯优量汇 SDK、百度联盟广告 SDK（百青藤）和爱奇艺联盟 SDK。TapADN SDK 通过 SDK 自动采集方式，在您同意后且本游戏调用广告初始化、加载、展示或效果上报功能时处理 OAID、AndroidID 等设备标识及必要的设备、网络、应用和广告交互信息；不设置定时采集，也不会在本游戏未向您提供服务或仅在后台运行时主动请求广告服务。各 SDK 的详细规则见本政策第四部分。
  • 我们使用友盟同欣（北京）科技有限公司运营的 U-APP 移动统计 SDK。您同意后，该 SDK 会通过 SDK 自动采集方式读取 AndroidID、OAID、GUID、GAID 等设备标识，并处理设备、网络、应用版本、页面访问、功能点击和会话信息，向友盟服务器传输，用于生成去标识化设备标识、APP 运行统计、用户行为趋势分析和异常诊断。预初始化和正式初始化均在您点击“同意”后执行；您不同意时不会调用。
  • 当您使用 TapTap 登录、合规认证、成就、排行榜、云存档、评价、更新唤起或 REP 功能时，TapSDK 会读取 AndroidID，用于确保设备系统兼容及定位解决服务故障；还会处理系统版本、设备型号、CPU、内存和网络类型等必要信息。
  • 个性化广告并非本游戏核心功能。拒绝或关闭个性化广告不会减少广告数量，但广告内容与您的相关度可能降低。

一、我们如何收集和使用个人信息

1. 保障游戏基础运行与安全

为保障本游戏正常运行、适配您的设备、诊断故障并维护网络与账号安全，我们可能处理以下信息：

  • 设备、标识与系统信息：设备品牌、制造商、型号、操作系统及版本、屏幕尺寸与分辨率、CPU、内存、存储空间、系统语言、时区，以及根据具体功能和 SDK 配置可能处理的 AndroidID、OAID、设备 MAC 地址等设备标识；
  • 传感器列表信息：Unity3D 框架可能在应用启动、引擎初始化或检测设备输入能力时，查询设备是否支持加速度计、陀螺仪、重力、线性加速度、旋转矢量、磁场等特定类型传感器，用于识别传感器类型、输入适配、设备兼容和故障排查。该项是查询设备支持的传感器类型列表，不等同于持续读取传感器测量数值；如具体游戏或广告功能需要使用传感器数值，我们会按照相应功能和第三方 SDK 条款另行处理。
  • 应用信息：本游戏包名、版本号、安装时间、安装渠道、前后台状态；
  • 网络信息：IP 地址、网络类型、网络状态、Wi-Fi 状态、运营商信息；
  • 日志与诊断信息：启动、点击、页面访问、运行日志、崩溃日志、性能数据及错误信息。

收集方式：在您同意本政策后，由本游戏在运行过程中处理，或由实现相关功能的第三方 SDK 自动采集。上述信息主要用于完成游戏引擎运行、网络连接、资源加载、设备适配、异常排查、广告监测归因、反作弊和安全保障。具体信息会因设备型号、系统版本、功能配置及您是否授权而不同。

2. TapTap 账号登录、实名认证与防沉迷

当您选择使用 TapTap 账号登录时，TapTap 登录 SDK 会在您授权后向我们提供实现登录所必要的账号标识、昵称、头像、登录状态和授权凭证。我们使用这些信息完成登录、识别账号和同步相关游戏服务。

TapSDK 处理设备信息的特别说明：收集方式为 TapSDK 自动采集；收集范围包括系统版本、设备型号、设备 CPU 信息、设备内存信息、网络类型和 AndroidID；处理目的是确保设备系统兼容，并在发生服务故障时进行针对性排查和优化。收集频次为：系统版本、设备型号、CPU、内存和网络类型在每次应用冷启动时获取一次，AndroidID 在 TapSDK 初始化及您发起 TapTap 授权时获取一次。TapSDK 还可能查询设备上是否已安装 TapTap 客户端，用于登录授权、更新唤起、评价或 REP 跳转。本游戏仅在您同意本隐私政策后初始化并调用 TapSDK。

为履行网络游戏实名认证及未成年人防沉迷义务，实名认证信息可能由 TapTap 合规服务依法处理。我们通常仅接收认证状态、年龄区间或是否受防沉迷限制等必要结果；如依法需要由我们直接处理实名身份信息，我们会另行向您说明并取得必要授权。实名身份信息属于敏感个人信息，拒绝提供可能导致您无法进入游戏或受到相应功能限制。

3. 游戏数据、排行榜、成就与云服务

为保存游戏进度并提供签到、关卡、道具、金币、装扮、排行榜、成就及云存档等功能，我们可能处理您的 TapTap 账号标识、游戏昵称、头像、关卡进度、分数、成就、签到记录、道具与虚拟资产记录、游戏设置和云存档数据。排行榜中可能向其他用户展示您的昵称、头像、分数和排名。

4. 广告展示与广告效果分析

本游戏通过 Dirichlet 聚合广告 SDK（TapADN SDK）聚合展示激励视频、插屏和横幅广告，并根据实时投放策略调用穿山甲广告 SDK、腾讯优量汇 SDK、百度联盟广告 SDK（百青藤）或爱奇艺联盟 SDK。为完成广告请求、展示、频次控制、效果统计、监测归因、反作弊及保障服务稳定，Dirichlet 及当次实际提供广告的合作方可能处理设备信息、应用信息、网络信息、广告展示、点击、关闭、观看完成及转化等交互数据。详细范围见本政策第四部分的第三方 SDK 清单。

TapADN SDK 的采集方式、场景与频次：相关信息由 SDK 自动采集，仅在您同意本政策后、本游戏位于前台并调用 SDK 初始化、广告加载、广告展示、广告互动或效果上报等相关功能时触发。设备标识、设备、网络和应用基础信息可能在 SDK 初始化以及每次必要的广告请求、监测归因或反作弊上报时读取或随请求传输；展示、点击、关闭、观看完成和转化等信息仅在对应行为发生时处理。TapADN SDK 不设置定时采集逻辑；我们不会为了单独获取 AndroidID、OAID 等设备标识而在后台或无广告业务场景时重复调用 SDK，并会将广告请求限制在实现当次广告功能所必需的最低频率。

当您主动点击应用下载类广告时，广告服务方可能展示待下载应用的名称、开发者、版本、大小、功能介绍、权限列表及隐私政策，并在您确认后执行下载或跳转安装；我们不会以欺骗、误导或强迫方式要求您下载、安装应用。

5. 个性化广告设置

广告服务方可能根据设备标识、粗略地域、应用总体安装使用情况及广告浏览、点击、转化等操作记录，通过算法分析您的偏好并展示相关性更高的广告。您可以进入游戏设置，点击“个性化广告设置”，通过“个性化广告”开关随时开启或关闭该功能；本游戏会保存您的选择，并在下次启动时将该选择重新同步给 Dirichlet 聚合广告 SDK。您也可以使用设备系统提供的广告隐私设置限制广告跟踪。

关闭个性化广告不会减少广告展示数量，您仍会看到广告，但广告内容与您的兴趣相关度可能降低。如游戏内入口暂时无法使用，您还可以通过本政策“联系我们”所列邮箱提出相关请求。

6. 运营统计

为了解本游戏的使用情况、改进功能并定位异常，我们使用 U-APP 移动统计 SDK（运营方：友盟同欣（北京）科技有限公司；其隐私政策同时列明北京锐讯灵通科技有限公司）。在您同意后，该 SDK 会通过 SDK 自动采集方式读取 AndroidID、OAID、GUID、GAID 等设备标识，并处理设备品牌与型号、操作系统、屏幕、应用包名与版本、IP 地址、网络类型、运营商、页面访问、功能点击、会话时长、崩溃及性能数据，并向友盟服务器传输。处理目的为生成去标识化终端设备标识、提供 APP 运行统计与数据去重、页面及事件分析、用户行为趋势与版本渠道分析、异常诊断和产品优化。我们不会仅基于该等统计信息识别您的直接身份。

U-APP 的触发时机与频次：首次安装或隐私政策更新后，只有您点击“同意”，本游戏才依次调用 UMConfigure.preInit 和 UMConfigure.init；您不同意时不会调用。后续冷启动仅在本地仍保存当前版本同意记录时进行预初始化和正式初始化。设备标识及必要的设备、网络和应用基础信息可能在初始化、建立新的统计会话或必要故障恢复时读取；页面和功能事件仅在对应行为发生时记录并按 SDK 机制上报；崩溃信息仅在发生崩溃时处理。事件上报可能携带已经形成的统计标识，不代表每次事件都重新读取 OAID。

U-APP 可选字段配置：本版本在友盟初始化前显式关闭 IMEI、IMSI、ICCID、Wi-Fi MAC 地址和应用列表信息的采集，不使用友盟移动统计的可选位置统计功能。

7. 您主动提供的信息

当您使用兑换码、客服、投诉、建议、账号注销或参加运营活动时，我们会根据具体场景处理您主动提交的兑换码、账号标识、联系方式、问题描述、截图及履行活动所必需的信息。我们会在相关页面另行说明信息用途；您拒绝提供非必要信息不会影响核心玩法。

8. 收集和使用目的发生变化

若我们拟将您的个人信息用于本政策未载明的其他目的，或处理目的、方式、种类发生重大变化，我们会通过弹窗、页面提示或其他适当方式再次告知，并依法取得您的同意。

9. 系统权限清单

系统权限不等同于我们一定会收集相关信息。只有在具体功能需要且符合法律要求时，我们或相关 SDK 才会调用相应权限。您可在设备“设置—应用—权限管理”中查看、关闭或重新授权。

二、Cookie、设备标识和同类技术

本游戏及第三方 SDK 可能使用设备标识符、本地存储、缓存和其他同类技术，记录您的登录状态、游戏设置、广告展示频次及安全状态。我们仅将这些技术用于本政策所述目的。您清除应用数据、重置设备广告标识或卸载本游戏后，部分本地记录会被删除或重置；依法需要保留的记录除外。

三、我们如何存储个人信息

1. 存储地点

我们将在中华人民共和国境内运营过程中收集和产生的个人信息存储于境内。目前，我们不会主动将您的个人信息传输至境外。若未来发生跨境提供，我们会依法履行告知、取得单独同意及其他法定程序。

2. 存储期限

我们仅在实现本政策所述目的所必需的最短期限内保存个人信息，法律法规另有规定的除外。期限届满后，我们会删除或匿名化处理相关信息。具体期限会根据账号存续状态、服务需要、安全审计、争议解决及法定义务确定。

3. 本地数据

部分游戏进度、设置、隐私选择及缓存会存储在您的设备本地。您清除应用数据或卸载本游戏可能导致这些本地数据无法恢复；已经同步至 TapTap 或其他云服务的数据，按照相应服务规则处理。
